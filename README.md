# Universal LED Builder — releases

This repository holds only the installers for Universal LED Builder and the
small `latest.json` file the app reads to see whether a newer version is out.
There is no source code here.

- **Download:** see [Releases](../../releases/latest). Mac: the `.dmg`.
  Windows: the `-setup.exe`.
- **Updates:** the app checks this page's `latest.json` when it opens and once
  a day. It sends no usage data. It only installs an update when you click
  Install, and only if the update is signed by the publisher.
